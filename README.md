# Exercise: Variables and Data Types

Exercise code for the lesson **Exercise: Variables and Data Types** in the C# Full-Stack Bootcamp on [ask-codey.com](https://www.ask-codey.com).

You will solve 28 small problems in `VariablesExercise/Program.cs`: declaring variables, choosing data types, and calculating with expressions. Tests check every answer.

## Run it

```bash
dotnet run --project VariablesExercise
```

In Visual Studio, open `VariablesExercise.slnx` and press **Ctrl+F5**.

## Check your answers

```bash
dotnet test
```

In Visual Studio, use **Test > Run All Tests**.

At first every test fails: that is expected. Each problem you solve turns one test green. A failing test's message says which problem it is and what it expected.

## The rules

- Print each answer on one line: the problem number, `)`, the variable's name, `: `, and its value. For example: `13) shotsTaken: 10`.
- Choose the right data type for every value. Use `decimal` for money.
- Give every value a meaningful name. Don't use magic numbers.

## Hand it in

When it works, push your solution to a public repo of your own on GitHub, then paste that repo's address into **Submit your exercise** on the lesson page at [ask-codey.com](https://www.ask-codey.com). That's what completes the lesson. The lesson page shows the Git commands, step by step.
